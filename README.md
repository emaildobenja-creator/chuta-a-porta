# Chuta a Porta!

Jogo de cartas de masmorra para 2 a 6 jogadores, cada um no seu celular. Inspirado na mecânica do Munchkin, com cartas e textos originais.

- Jogue em: https://emaildobenja-creator.github.io/chuta-a-porta/
- Salas online pelo Firebase Realtime Database (projeto `chuta-a-porta`). As regras do banco estão em `database.rules.json`.
- Instalável no celular (PWA): pelo menu do navegador, "Instalar app" ou "Adicionar à tela inicial".
